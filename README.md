# Content Automator

> **EN:** Desktop app for automated visual content production. Takes a subject
> reference and a scene reference, composes them through a generative image API,
> writes the caption and queues the post on a schedule. Tkinter GUI with a live log,
> APScheduler for timing, and a documented hook for the official Instagram Graph API.

Десктопное приложение для конвейерного производства визуального контента.
Берёт референс объекта и референс сцены, соединяет их через API генерации,
готовит пост с подписью и ставит его в расписание публикации.

## Зачем

При регулярном ведении визуальных площадок узкое место — не идеи, а производство:
подобрать кадр, привести к единому стилю, выгрузить, подписать, не забыть выложить.
Приложение сводит цикл к запуску: на выходе — папка готовых постов и планировщик,
который отдаёт их по расписанию.

## Как работает конвейер

```
references/     — референс объекта (то, что должно сохраниться)
source_images/  — референс сцены (поза, фон, свет, композиция)
        │
        ▼
image_editor.py / wavespeed_edit.py
   генеративный API: объект из первого кадра переносится
   в сцену, освещение и композицию второго
        │
        ▼
output/  — готовое изображение + подпись
        │
        ▼
APScheduler — постановка в расписание публикации
```

Отдельно вынесен `instagram_poster.py` с хуком под **официальный Instagram
Graph API**: он легально поддерживает запланированную публикацию для бизнес-
и creator-аккаунтов. Автопостинг через неофициальные библиотеки в конвейере
не используется — он нарушает правила площадки и ведёт к блокировкам,
поэтому по умолчанию приложение просто складывает готовый пост в `output/`.

## Особенности

- **Tkinter-интерфейс** с живым логом выполнения: видно, на каком шаге конвейер
  и почему упал, если упал
- **Фоновый планировщик** (`APScheduler`) с настраиваемым интервалом и лимитом
  постов за запуск
- **Тестовый режим** — прогон всего конвейера без публикации
- **Конфигурация в JSON** — промпт, интервал, лимит и подпись правятся без кода
- **Изоляция ключей** — все токены только из `.env`, в репозитории их нет

## Стек

Python 3.11 · Tkinter · APScheduler · requests · Pillow · генеративный image API

## Запуск

```bash
python -m venv venv && venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env                    # ключ API
copy config.example.json config.json      # промпт и расписание
python main.py
```

Положить исходники: референсы объекта в `references/`, референсы сцен
в `source_images/`. Результат появится в `output/`.

## Структура

| Файл | Назначение |
|---|---|
| `main.py` | GUI, оркестрация конвейера, планировщик, логирование |
| `image_editor.py` | обёртка над API генерации, ретраи и обработка ошибок |
| `wavespeed_edit.py` | низкоуровневый клиент API |
| `instagram_poster.py` | хук под официальный Instagram Graph API |
| `scheduler_app.py` | отдельный запуск планировщика без GUI |
| `test_editor.py` | тесты обёртки редактора |
